  1. Go to script.google.com and click New Project (name it TC JV Call Sheet).
  2. Delete everything in Code.gs, then click Copy Code.gs below and paste it in.
  3. Click the + icon next to Files → choose HTML → name it exactly Index (it creates Index.html).
  4. Click Download Index.html below (or copy this file), paste all of its code into Index.html, and click Save (Ctrl+S).
  5. (Optional for AI Updater) In Apps Script, click the ⚙️ Project Settings → Script Properties → Add property GEMINI_API_KEY with your Google AI Studio key.
  6. Click Deploy → New Deployment → Web app → Execute as: Me → Who has access: Only myself (or Anyone with link) → Deploy & authorize Google Drive!
