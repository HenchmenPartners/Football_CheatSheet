☁️ Host on GitHub Pages + Connect Your Firebase Database

Deploy this single file on GitHub Pages for free with real-time Firebase Firestore auto-save across all your coaches' phones, tablets, and laptops—protected by your password (Shopping90).

  1. Go to console.firebase.google.com → Create Project (e.g., tc-jv-playbook).
  2. In Firebase, go to Build → Authentication → Sign-in method and enable Anonymous.
  3. Go to Build → Firestore Database → Create database (Start in production mode), then paste the Firestore Rules below under the Rules tab and click Publish.
  4. Go to Project Settings (&gear;) → Your apps → Web (</>) → Register app → copy your firebaseConfig JSON object and paste it below.
  5. Click ⬇️ Download Ready-to-Deploy index.html below—it automatically bakes your Firebase config right into the file!
  6. Upload that index.html to a GitHub repository → go to Repo Settings → Pages → Branch: main / root → Save. Your live coaching link will be up in ~60 seconds!
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
